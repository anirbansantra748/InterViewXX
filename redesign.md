Use the **attached brand/moodboard image as the primary visual reference** and completely redesign the existing recruitment platform around this visual identity.

Do NOT simply change the colors of the current UI. Treat this as a **full product rebrand and design-system transformation**. The final website should feel like a real, distinctive recruitment product with its own recognizable visual language—not another generic Linear/Notion/Stripe-style SaaS template.

## CORE BRAND DIRECTION

The brand should communicate:

* Human potential
* Opportunity
* Progress
* Trust
* Technology without feeling overly futuristic
* Professionalism without feeling corporate or boring
* A sense of optimism and movement
* Human-centered hiring rather than résumé-centered hiring

The attached reference establishes the visual direction. Use it as the source of truth for the overall aesthetic, visual language, composition, shapes, typography hierarchy, color relationships, illustrations, photography treatment, icons, spacing, and brand personality.

The design should feel:

**Editorial + Human + Intelligent + Professional + Distinctive**

Avoid making it look like a typical recruitment dashboard.

---

# 1. CREATE A REAL BRAND SYSTEM

Build a consistent brand identity throughout the entire application.

### Logo / Brand Mark

Create or refine the existing logo into a distinctive abstract symbol that can work independently as:

* App icon
* Favicon
* Sidebar logo
* Loading animation
* Avatar/brand mark
* Mobile navigation icon
* Marketing illustration element

The logo should have an organic, recognizable silhouette inspired by the visual language of the attached reference, but it must feel like an original brand identity.

Do NOT use generic briefcase, handshake, building, résumé, or person icons as the primary logo.

The brand mark should visually communicate:

**people → movement → opportunity → growth**

Use the brand mark consistently throughout the application.

---

# 2. DISTINCTIVE VISUAL LANGUAGE

The biggest goal is differentiation.

Do not make every screen a collection of rectangular cards.

Introduce a recognizable visual language based on:

* Organic geometric shapes
* Soft asymmetric containers
* Subtle flowing forms
* Rounded but intentional shapes
* Editorial layouts
* Generous whitespace
* Carefully placed visual accents
* Human photography integrated into shapes
* Subtle curved paths representing career journeys
* Layered visual elements
* Small handwritten/editorial annotations where appropriate
* Strong typography-led sections

The organic shapes should become part of the brand's visual grammar.

Use them selectively. Do not decorate every component.

---

# 3. COLOR SYSTEM

Use a light-first palette based on the attached reference.

Primary direction:

* Warm off-white / ivory backgrounds
* Deep forest / dark green as the primary brand color
* Fresh emerald/green as the opportunity/action color
* Muted peach/coral as a secondary emotional accent
* Soft sage and pale mint backgrounds
* Charcoal rather than pure black
* Very light gray borders

Suggested conceptual roles:

**Deep Green**
Brand / navigation / primary CTA / important headings

**Emerald**
Progress / success / active states / positive actions

**Peach**
Human warmth / highlights / secondary accents

**Cream / Ivory**
Main page background

**Sage / Mint**
Subtle section backgrounds

**Charcoal**
Primary text

Do not turn the application into a green-colored website.

Green should be a strategic brand signal, not the background of everything.

Avoid:

* Neon green
* Excessive gradients
* Purple SaaS palettes
* Blue-heavy dashboards
* Black/dark-mode-first design
* Excessive glassmorphism

The product should be predominantly light.

# 13. SECURE CODE EXECUTION

The existing custom JavaScript sandbox is a major technical differentiator.

Do not expose unnecessary implementation details to ordinary users.

Instead, communicate security through subtle interface elements:

* Sandboxed execution
* Memory limits
* Restricted environment
* Secure execution
* Execution time
* Memory usage

Example:

**Secure execution**
`42 ms · 18.4 MB`

The product should communicate that code execution is isolated and controlled without making the interface look like a cybersecurity product.

# 27. FINAL DESIGN PRINCIPLE

When making design decisions, ask:

**"Could someone recognize this product from a screenshot without seeing the logo?"**

The answer should eventually be YES.

The combination of:

* Organic visual forms
* Distinctive brand mark
* Deep green + peach + ivory system
* Editorial typography
* Human photography
* Career-path visual metaphors
* Strong whitespace
* Human-centered copy
* Product-specific interface patterns

should make the platform visually recognizable.

Do NOT copy the attached reference literally.

Use it as the **creative foundation**, then develop a coherent original identity around the existing recruitment platform.

The final result should look like a **real venture-backed product with a mature design system**, while still feeling approachable and human.

Before implementing individual screens, establish the global design tokens, typography, colors, spacing, radius, shadows, buttons, forms, navigation, iconography, cards, and brand elements so every page feels like the same product.

**Do not leave the existing pages visually inconsistent. Apply the new identity across the ENTIRE website.**
